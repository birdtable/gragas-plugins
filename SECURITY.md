# Security policy

## Reporting a vulnerability

Report a vulnerability privately, through GitHub's private vulnerability reporting: the **Report a vulnerability** button on this repository's **Security** tab. Please do not open a public issue or pull request for it.

Say what the problem is, which plugin and version or commit it affects, and how to reproduce it. You will get an answer, and the report stays private until a fix is released.

## Supported versions

The latest tagged release of each plugin gets fixes.
